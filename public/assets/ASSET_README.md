# SiPeminjam UI assets

The `img/tools` SVGs are lightweight transparent illustrations used by the customer-facing catalog. They intentionally use a consistent blue/white visual language so the interface remains sharp at different sizes without external image dependencies.

Files: `laptop.svg`, `projector.svg`, `camera.svg`, `monitor.svg`, `box.svg`, plus `logo-blue.svg` and `logo-white.svg`.
